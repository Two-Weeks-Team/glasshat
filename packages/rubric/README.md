# packages/rubric (`glasshat.rubric`)

The `SynthesizedRubric` model + its JSON Schema, the shared BMAD scoring
vocabulary, the rubric **presets**, and validation. The Rapid Agent preset is
**4 criteria × 25%** (Technological Implementation, Design, Potential Impact,
Quality of the Idea) with **tie-break by listed order**. Implemented and tested
(used by the synthesizer, scorer, and report stages); CI-green.
