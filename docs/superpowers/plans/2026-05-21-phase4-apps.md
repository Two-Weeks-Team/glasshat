# Phase 4 — Surfaces (apps/api + apps/web)

> REQUIRED SUB-SKILL: superpowers:executing-plans. Split: **P4a** (`feat/arize-api`) + **P4b** (`feat/arize-web`).

**Goal:** Expose the engine over an HTTP API (FastAPI) and a two-viewport Next.js web app, both runnable/buildable in CI on the `mock` engine (no credentials). The two human gates (plan approve, score override) and the SSE live monitor are wired; the web build (`pnpm build` + `tsc` + `vitest`) is green and a Playwright smoke runs against the mock API.

---

## P4a — `apps/api` (FastAPI · `glasshat.api`)

Workspace member `apps/api` → `glasshat.api`. Deps: glasshat-pipeline, fastapi, uvicorn. Tested with `fastapi.testclient.TestClient` + `default_deps()` (mock/memory) — zero creds.

Contract (OpenAPI auto from FastAPI):
- `GET /health` → `{status:"ok"}`.
- `POST /api/evaluate` `{rubric_source, deck_text?, repo_url?, mode}` → runs pipeline, returns `RunRecord` (+ persists). (MVP: synchronous; gates exposed separately.)
- `POST /api/plan` `{...EvaluationInput}` → returns the `PlanObject` only (human gate 1 preview).
- `GET /api/runs/{run_id}` → stored `RunRecord` or 404.
- `GET /api/runs/{run_id}/stream` (or `POST /api/evaluate/stream`) → `text/event-stream` of pipeline events (SSE; spike-E cadence optional).
- `POST /api/runs/{run_id}/override` `{criterion_id, score, reason}` → human gate 2; appends override to the stored record (audit trail).

TDD (TestClient): health; plan preview returns 6 hats + criteria; evaluate returns RunRecord with self-correct delta (over-confident-yellow deps via dependency override or a seeded app); get run 200/404; stream yields `event: complete`; override updates stored record. `app_factory(deps=None)` lets tests inject mock deps.

Gate + PR (merge commit).

## P4b — `apps/web` (Next.js 16 · pnpm, standalone — not a uv member)

`apps/web/`: App Router. `app/page.tsx` (choose viewport), `app/judge/**`, `app/participate/**` (per hybrid-mode-spec §7). `components/{shared,judge,participate}` (ScoreBar, AuditDrawer, KanbanCard, RankTable, IterateBar, 3D constellation via react-three-fiber + PCA/UMAP projection of criterion vectors, SSE hook). `lib/{api.ts,sse.ts}` typed against the rubric JSON Schema. Tailwind tokens (OKLCH retained).

CI: a `web` job — `pnpm install --frozen-lockfile` → `pnpm lint` (eslint) → `pnpm typecheck` (`tsc --noEmit`) → `pnpm test` (vitest unit) → `pnpm build` (next build) → `pnpm exec playwright test` (smoke against mock API or static). All must be green (goal item 3 build green + item 6 3D self-correction surfaced).

Gate + PR (merge commit). Apps phase complete when both merged.
