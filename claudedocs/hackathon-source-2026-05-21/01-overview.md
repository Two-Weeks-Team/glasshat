# Google Cloud Rapid Agent Hackathon: Complete Overview

## Hackathon Theme & Description
"Building Agents for Real-World Challenges" focuses on creating agents that "accomplish tasks for you" rather than traditional chatbots. The initiative targets builders of all technical levels to develop agents capable of reasoning, planning, and executing tasks using Gemini's advanced capabilities combined with partner technologies.

## Partner Tracks (6 Total)
1. **Arize**
2. **Elastic**
3. **Fivetran**
4. **GitLab**
5. **MongoDB**
6. **Dynatrace**

## Prize Structure: "Partner Bucket" System
Three identical prize buckets—one per featured partner track. Competitors within each partner category compete separately:

**Per Partner Track:**
- 1st Place: $5,000
- 2nd Place: $3,000
- 3rd Place: $2,000

**Total Prize Pool:** $60,000 across all six tracks

## What to Build
Functional agents powered by Gemini and Google Cloud Agent Builder that integrate a partner's Model Context Protocol (MCP) server. Requirements include:
- Move beyond chat-based responses
- Handle multi-step missions through planning and tool usage
- Demonstrate meaningful partner integration
- Solve real-world challenges in personal/professional contexts
